# Mod Nourriture (Fabric)

## Objectif
Ajouter de la nourriture, des moyens de la préparer
et des animations réalistes (couper, cuisiner, manger).

## Étape 1 : Planche à découper
- Bloc "Planche à découper"
- Item "Couteau"
- Clic droit avec le couteau sur la planche avec un
  ingrédient : animation de coupe, puis résultat
- Premier aliment : Tomate -> Tranches de tomate
